# 07. Preguntas abiertas

Formato: pregunta, opciones, recomendación actual. Se cierran moviéndolas a la sección "Cerradas" con la decisión y la fecha.

## Abiertas

**P1. Nombre del modpack.**
Ideas: Incremental Craft, Idle Ascension, Blockonomy, Infinite Yield, Multiverse Tycoon, Ascend.
Recomendación: decidir más adelante; "Incremental Craft" como nombre de trabajo.

**P2. ¿Saldo virtual o monedas físicas?**
Recomendación: virtual como saldo principal (escala a números enormes). Monedas físicas solo como ítem decorativo o para tiendas específicas.

**P3. ¿Cómo convive la capa idle virtual con las fábricas de Create (que no corren offline)?**
Recomendación: idle virtual para offline y progreso base; Create como multiplicador activo que rinde mucho más mientras juegas. Evaluar una mecánica de "convertir fábrica en generador virtual" (registrar el rendimiento promedio de una fábrica y que siga produciendo virtualmente offline) como mejora tardía. 🟡

**P4. ¿Qué pasa con lo construido al hacer prestigio?**
Ver [04](04-prestigio.md). Recomendación: hub se conserva, dimensiones se regeneran, llaves se pierden.

**P5. ¿El jugador puede fabricar cosas libremente o todo se compra?**
Opciones: (a) crafteo vanilla libre, (b) todo comprado, (c) híbrido: herramientas y máquinas clave se compran primero y luego se desbloquea su receta.
Recomendación: (c).

**P6. Tienda: ¿GUI propia o reutilizar algo existente?**
Recomendación: FTB Quests (recompensas por comando) para el prototipo; GUI propia si la experiencia se siente torpe.

**P7. Single player, cooperativo o servidor?**
Recomendación: diseñar para single player y cooperativo pequeño (FTB Teams comparte saldo). Sin economía entre jugadores al inicio.

**P8. Versión de Minecraft.**
Recomendación: 1.21.1 NeoForge. Confirmar en S5.

**P9. ¿Romper a mano tiene sentido después de la fase 1?**
Riesgo clásico: el clic queda obsoleto. Ideas: mejoras de clic que escalan con la producción idle (ej. cada clic da 1% de tu producción por segundo), eventos temporales que piden interacción ("bloque dorado" estilo Cookie Clicker), o el bloque regenerativo de cada nuevo tier se empieza rompiendo a mano.

**P10. Licencia y distribución.**
Revisar licencias de cada mod antes de publicar en CurseForge/Modrinth.
