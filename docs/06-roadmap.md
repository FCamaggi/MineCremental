# 06. Roadmap y sesiones

## Definición de MVP · Propuesta

Jugable de principio a primer prestigio en 2 a 3 horas:
- Tier 0 completo (isla, tierra/piedra/madera regenerativas, mejoras, generadores idle).
- Tier 1 (La Cantera) con Create básico.
- Prestigio capa 1 con 5 a 10 mejoras de Esencia.
- 20 a 30 quests que guíen.
- Ganancia offline.

## Fases

| Fase | Entregable |
|---|---|
| 0. Diseño base | Este set de documentos (hecho en v1) |
| 1. Diseño detallado | Una sesión por tema (ver abajo) |
| 2. Prototipo técnico | Vertical slice de [05](05-stack-tecnico.md) |
| 3. MVP | Lo definido arriba |
| 4. Expansión | Tiers 2 a 6, prestigio capa 2, desafíos |
| 5. Publicación | CurseForge / Modrinth, página, capturas |

## Sesiones de diseño planificadas

Cada sesión: un tema, sesión limpia, leer `CLAUDE.md` + documento correspondiente, cerrar con nota en `docs/sesiones/`.

| # | Tema | Documento | Resultado esperado |
|---|---|---|---|
| S1 | Base del proyecto | Todos | Estructura y borradores v1 (esta sesión) |
| S2 | Primeros 30 minutos | 01 | Secuencia exacta de mejoras, costos y desbloqueos del Tier 0 |
| S3 | Economía y balance | 02 | Fórmulas definitivas, hoja de cálculo que simula la progresión |
| S4 | Prestigio | 04 | Decidir qué se conserva del mundo, lista de mejoras de Esencia |
| S5 | Verificación técnica | 05 | Confirmar mods y versiones, investigar HUD y stages, decidir si hace falta mod propio |
| S6 | Prototipo | 05 | Vertical slice funcionando |
| S7 | Tier 1 y Create | 03 | Cantera, cadenas de procesamiento, qué máquinas se compran vs se fabrican |
| S8 | Quests | nuevo doc | Árbol de quests del MVP |

El orden es flexible; S5 puede adelantarse si se quiere validar factibilidad antes de diseñar en detalle.
